# SkillGap AI

SkillGap AI is an AI-powered system that compares a candidate's resume with a job description and identifies skill gaps.

Features
• Resume PDF parsing
• Skill extraction using NLP
• Semantic similarity scoring
• Skill gap analysis
• Resume improvement suggestions
• Interactive dashboard with Streamlit

Tech Stack
Python
Streamlit
Sentence Transformers
Scikit-learn
NLTK
Matplotlib
Plotly

How to Run

pip install -r requirements.txt
streamlit run app.py
